## 维护约定

- **改 API 先改 [api.md](api.md)**——CLAUDE.md §5 只留端点清单，README 只留链接，字段级契约仅此一份；
- 域文档写「为什么与取舍」，操作步骤归 [运维与启动](运维与启动.md)，硬约束归 `CLAUDE.md`；
- 新的架构决策 = 新增一篇 ADR（顺延编号），不回改旧 ADR；
- 过程性总结（重构记录、迁移笔记）直接进 `archive/` 并加时点横幅，不放主目录。
